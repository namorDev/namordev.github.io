Today I came across something that made me excited about learning with AI: Matt Pocock's /teach skill. If you enjoy picking up new things, this might be worth a look.

I am currently learning LazyVim, so the idea of having a learning plan tailored to what I already know immediately caught my attention. There is plenty of material out there. Figuring out where to start and what to practise next is often the harder part.

What is a skill?

Think of a skill as a reusable set of instructions for an AI agent. It can include supporting resources and scripts, giving the agent a process to follow for a particular task.

Matt Pocock shares practical advice on using AI for software development. His skills repository contains a collection of these workflows, including /teach.

What does /teach do?

It starts by asking about your goals and existing knowledge, then creates lessons around your answers. These are saved locally as HTML pages and can include visuals, interactive elements, and quizzes. You return to the same folder for later lessons, so your learning can build across sessions.

Getting started

You will need Node.js for the installer. Run the following command and select the teach skill and the coding agent you use: 

npx skills@latest add mattpocock/skills

Create a dedicated folder for your learning topic, open it in your agent, and invoke /teach. For LazyVim, I could start with a request like:

I want to learn LazyVim and become comfortable using it for everyday development. Help me work out where to start, based on what I already know.

If you are new to OpenCode, OpenCode School offers a free introduction to the agent and its core concepts. Its learning exercise walks through setting up /teach specifically for OpenCode.

What appeals to me is having a clear next step. I still need to spend time in the editor and practise, but a course shaped around my questions sounds like a useful way to keep moving. LazyVim gives me a concrete topic to try it with.
