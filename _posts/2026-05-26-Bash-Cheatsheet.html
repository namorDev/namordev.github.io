In this cheatsheet, we'll cover some of the most useful keyboard shortcuts for navigating and using the Bash shell. Whether you're a beginner or an experienced user, these shortcuts can help you work more efficiently and effectively with AI tools and applications.

Bash, Shell, Command Line, Terminal - What now?

Before we dive into the shortcuts, let's clarify some terminology. The Bash shell is a command-line interface that allows you to interact with your computer's operating system. The terminal is the program that provides access to the command line, and the command line is where you type commands to execute tasks on your computer. The term shell is often used interchangeably with terminal, but technically, the shell is the program that processes your commands, while the terminal is the program that provides access to the shell. Whereas the term Bash (short for "Bourne Again SHell") is just one of many different shells available, but it is the most commonly used shell on Linux and macOS systems. So when we talk about Bash shortcuts, we're specifically referring to keyboard shortcuts that can be used in the Bash shell.

Keyboard Shortcuts

Here are some of the most useful keyboard shortcuts for navigating and using the Bash shell:

  • Ctrl + A: Move the cursor to the beginning of the line.
  • Ctrl + E: Move the cursor to the end of the line.
  • Ctrl + U: Cut the text from the cursor to the beginning of the line.
  • Ctrl + K: Cut the text from the cursor to the end of the line.
  • Ctrl + W: Cut the word before the cursor.
  • Ctrl + Y: Paste the last cut text.
  • Ctrl + L: Clear the terminal screen.
  • Ctrl + C: Cancel the current command.
  • Ctrl + D: Exit the terminal.
  • Ctrl + R: Search through command history incrementally.
  • Ctrl + X, Ctrl + E: Edit the current command in the default editor.
  • ^string1^string2^: Run the previous command with string1 replaced by string2.
  • !!: Run the previous command.
  • !n: Run the nth command from history.
  • sudo !!: Run the previous command with sudo.
